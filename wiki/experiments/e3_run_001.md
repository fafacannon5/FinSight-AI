# E3 run 001 — answer quality vs. top-k

**Hypothesis:** more context (larger k) raises correctness, but groundedness may drop because the model
has more docs to mix and mis-cite.

**Config:** FiQA dev, 20 answerable questions (seed 42), corpus minus the 116 removed docs, exact TorchKNN
384-d, top-10 retrieved once, k ∈ {1, 3, 5, 10} = first k docs (each cut to 1,000 chars).
LLM `openai/gpt-oss-120b` via Groq, temperature 0, reasoning_effort low, max_tokens 400
([LLM choice](../decisions/llm_choice.md)). 80 calls, 76,038 tokens. Scripts: `scripts/e3_generate.py`,
`scripts/e3_analyze.py`.

**Scoring:** [rubric](e3_rubric.md), joint consensus scores by J and H (one agreed score per row; the CSV's `scorer` column says J only). Means use **answered rows only**; rows marked `refused` /
`refused-wrongly` are counted separately.

## Verdict: confirmed (small sample)

- **Correctness rises with k** (2.36 → 2.65) and the model answers more often (11 → 17 of 20).
- **Groundedness falls with k** (3.00 at k=1 → 2.65 at k=10): with 10 docs the model adds claims that the
  docs only loosely support. Trade-off point: **k = 5** keeps groundedness near 2.9 with correctness 2.53.
- **The model's own refusals are over-cautious at small k:** 9 of 20 refused at k=1. Refused-wrongly
  appears only at k ≥ 3 (2 per k), i.e. the answer was in the docs but the model still refused.
- When a labelled doc is in the top-k, correctness is ~2.9; without one it is ~2.1–2.4 — answers from
  unlabelled docs are often still useful (FiQA labels are incomplete), but less often fully right.

## Caveats

- n = 20 questions. Scores are a J+H consensus, not two independent sets, so inter-rater agreement
  (Cohen's κ) cannot be computed; the report should say "scored jointly by both members".
- Means at each k are over different answered subsets (refusals excluded), so they are not strictly paired.
- Each k uses the same top-10 ranking; the LLM is hosted and may change (model id + date stored per answer).
