# Workflow: Ingest

Parent: [AGENTS.md](../../AGENTS.md)

**Trigger:** a new file in `raw_sources/` (paper, course announcement, professor feedback).

1. Read it fully. Tell the member the 3 points most relevant to this project.
2. Write a summary page (`wiki/literature/` for papers, `wiki/decisions/` for course feedback).
3. Update `wiki/index.md` and any page it changes; update `wiki/overview.md` if direction shifts.
4. Append `ingest` entry to `wiki/log.md`. Never modify files inside `raw_sources/`.
