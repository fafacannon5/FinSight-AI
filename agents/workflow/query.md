# Workflow: Query

Parent: [AGENTS.md](../../AGENTS.md)

**Trigger:** a research or design question ("why IVF?", "what τ range?", "IVF 和 HNSW 有什么区别").

1. Read `wiki/index.md`, then the relevant pages.
2. Answer with links to wiki pages (and to papers in `raw_sources/papers/` when used).
3. Non-trivial answer → save as a wiki page and add it to `wiki/index.md`.
   A design choice → `wiki/decisions/<topic>.md` (context · options · decision · consequences).
4. Append `query` entry to `wiki/log.md`.
