# AI disclosure

Parent: [AGENTS.md](../../AGENTS.md)

CS 541 policy: AI tools may be used for brainstorming, debugging and understanding concepts; submitted work
must reflect the students' own understanding; **AI use must be disclosed**. Undisclosed AI-generated work
is academic dishonesty.

Rules for agents:
1. Commit messages the agent suggests for agent-assisted code end with a trailer, e.g. `Assisted-by: Cursor` / `Codex` / `Claude`.
2. Keep `AI_USAGE.md` (repo root) current: one row per module — tool, what it did
   (scaffold / hint / full code / debug / review), which member reviewed it.
3. Never write text that pretends agent work was done by hand, and never strip disclosure.
4. The final report's "Use of AI Tools" section is generated from `AI_USAGE.md`.
