# Activity log format

Parent: [AGENTS.md](../../AGENTS.md)

Append-only, newest at the top of `wiki/log.md`:

```
## [YYYY-MM-DD] {operation} | {description}
- bullet facts (numbers with units)
- Pages updated: ...
```

Operations: `milestone` · `experiment` · `ingest` · `query` · `decision` · `lint`.
