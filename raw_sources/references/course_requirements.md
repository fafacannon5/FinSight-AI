# CS 541 — course requirements relevant to the project

Source: CS 541 Fall 2026 syllabus (Instructor: Zhaozhuo Xu) and the project slide. Immutable reference.

## Project assignment (slide)
- Group project (≤ 4 members; we are 2): design, implement and analyze an AI-based system aligned with course outcomes.
- Must: (1) clearly articulate a problem and its relevance, (2) use one or more techniques covered in the course,
  (3) include experimentation and evaluation with real or synthetic datasets.
- Example themes: RAG for LLM question answering; neural network from scratch; fine-tuning for a downstream task.
- Deliverables: proposal (CS541_Project_template.pdf structure), final report (same structure),
  code repository (GitHub or zip), recorded presentation (10 minutes, video file).

## Schedule
- Week 10: proposal due · Week 12: midpoint check-in · Week 13: final report, code repo, 10-min video.
- Final project = 20% of course grade. Late: 1–6 days −20%; > 1 week = 0.
- File naming: `assignmentname_username`. Deadlines 11:59 pm Eastern.

## Learning outcomes the project should show
- CLO2: evaluate computational efficiency (running time, memory).
- CLO3/CLO4: formulate a real problem and pick suitable algorithms.
- CLO5: implement learning algorithms in PyTorch.
- CLO6: classic algorithms incl. K-nearest neighbors.
- Course topics used: KNN & similarity search (W10), PCA / random projection (W5), K-means (W4), evaluation metrics (W2, W12).

## AI policy
AI tools allowed for brainstorming, debugging, understanding concepts. Submitted work must represent the
students' own understanding. Undisclosed AI-generated work = academic dishonesty. **Disclose AI use.**
Undergraduate honor pledge must be written and signed on submitted work if any member is an undergraduate.

## Software
Python 3.x, PyTorch, Jupyter; Git and GitHub for final project submission.
